# Posters

Put poster images in this folder, then point a film at one in `js/films.js`:

```js
{ title: "Hereditary", ..., poster: "hereditary.jpg" }
```

- Films without a `poster` get a generated gradient instead.
- Suggested size: 2:3 portrait, around 600×900px, JPG or WebP.
- Only use artwork you have the rights to use (press kits, licensed images, your own).
